## 📖 Project Overview
Moment Maker is a modern, responsive event planning website completely generated using Generative AI tools. This project was created as part of our Generative AI course assignment to demonstrate the power of AI in web development.

This platform helps users plan their special moments like birthdays, weddings, and corporate events with ease.

## ✨ Key Features
-  Beautiful and Responsive UI/UX Design
-  Event Categories (Birthday, Wedding, Corporate)
-  Service Booking Interface
-  Gallery and Testimonials Section
-  Contact and Inquiry Form
-  Fully Responsive for Mobile & Desktop

## 🛠️ Technologies & AI Tools Used

**AI Tools:**
- Lovable AI (for complete website generation)
- ChatGPT / Meta AI (for prompt engineering and content)
- GitHub (for version control and hosting)

**Frontend Technologies (Generated by AI):**
- React.js / Next.js
- Tailwind CSS
- TypeScript / JavaScript

## 🤖 Prompts Used
The website was generated using detailed prompts in Lovable AI, such as:
> "Create a modern and elegant event planning website called Moment Maker with hero section, services, gallery, and contact form. Use soft pastel colors and professional typography."

Multiple iterations and refinements were done to achieve the final result.
